Features & UI Structure

The application is designed with a clean, user-centric interface. Below are the key screens and their primary functions as defined in the UI/UX plan. This covers both the public-facing mobile app for users and the web-based dashboard for mosque administrators.

🏠 Home Screen

  • Interactive map view with GPS
  • Toggle for list view of mosques
  • Search bar for name or city
  • Modal for filtering by facilities

🕌 Mosque Profile

  • Photo gallery and address
  • Dynamic prayer times table
  • Icon-based facility list
  • Event list and user reviews
  • "Get Directions" button

🗓️ Event Page

  • Full event title and description
  • Date and time information
  • Optional RSVP button for users

⭐ Review Submission

  • Interactive 1-5 star rating
  • Text comment box
  • Clear submission action

📊 Admin Dashboard

  • Sidebar navigation layout
  • CRUD interfaces for all data
  • Review management and approval
  • Data summaries and charts

🔐 Security & Auth

  • JWT for secure sessions
  • Role-based access control (RBAC)
  • Admin approval for mosque claims
  • Moderation tools for reviews
